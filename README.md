# 🇵🇪 Calculadora de Beneficios Laborales – Perú

Tus derechos laborales, más fáciles de calcular.

Una herramienta desarrollada en Python, diseñada para el mercado laboral peruano, que permite calcular y estimar de manera rápida y sencilla los principales beneficios y derechos laborales establecidos en la normativa peruana.

El proyecto busca facilitar el acceso a información laboral, ofreciendo herramientas prácticas tanto para trabajadores como para empleadores.

# Funcionalidades
💰 Sueldo: cálculo y estimación de remuneraciones.
🏦 CTS: cálculo de la Compensación por Tiempo de Servicios.
🎁 Gratificaciones: estimación de gratificaciones de julio y diciembre.
🌴 Vacaciones: cálculo de remuneración vacacional y vacaciones truncas.
📄 Liquidación: estimación de beneficios sociales por cese laboral.
⚖️ Otros beneficios laborales: herramientas relacionadas con los derechos del trabajador peruano.

# Tecnologías utilizadas
Python: lenguaje principal de desarrollo.
Hugging Face Spaces: plataforma utilizada para el despliegue de la aplicación.
🎯 Objetivo del proyecto
Desarrollar una herramienta tecnológica intuitiva y accesible que permita a los trabajadores peruanos conocer y estimar sus beneficios laborales, simplificando cálculos que normalmente requieren tiempo y conocimientos específicos.

# Aviso importante
Los resultados proporcionados por esta herramienta son estimaciones referenciales y no constituyen asesoría legal ni un cálculo oficial. Los montos pueden variar según el régimen laboral, las condiciones contractuales y la normativa aplicable.
